# cl-cmatrix

`cl-cmatrix` is a Matrix-style digital rain terminal screensaver for SBCL.
It supports 256-color trails, terminal resizing, and clean restoration of the
terminal state when the program exits.

The animation is compatible with upstream `cmatrix` 2.0 for its classic
glyphs and command-line behavior. It also provides katakana and binary glyph
sets, named color schemes, deterministic seeds, and a library API.
